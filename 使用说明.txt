========================================
A股看板系统 - 使用说明
========================================

一、系统简介
----------------------------------------
本系统是一个A股市场看板，包含以下页面：
1. 市场情绪：大盘指数、涨跌家数、涨跌停、ADL腾落指标
2. 板块行业：同花顺行业+概念题材热力图、涨幅矩阵、K线下钻
3. 个股排行：全市场个股涨跌幅排行
4. 宏观环境：全球权益、美债利率、国内宏观经济、跨市场联动对比

二、环境要求
----------------------------------------
- 操作系统：Windows 10/11
- Python版本：Python 3.8 或更高
- 浏览器：Chrome / Edge（推荐）

三、安装步骤
----------------------------------------
1. 安装Python
   - 下载地址：https://www.python.org/downloads/
   - 安装时勾选 "Add Python to PATH"

2. 安装依赖包
   - 打开cmd（命令提示符）
   - 进入项目文件夹：cd 你的路径\A股看板系统
   - 执行：pip install -r requirements.txt

3. 启动服务
   - 双击 "启动数据服务.vbs"
   - 或者在cmd中执行：python server.py

4. 打开看板
   - 用浏览器打开 index.html 文件
   - 或者访问：http://localhost:5000

四、数据来源说明
----------------------------------------
本系统数据来自多个来源：

1. Tushare（公网API）
   - 大盘指数K线、北向资金、两融等
   - 已内置token，无需额外配置

2. 东方财富（公网API）
   - 实时行情、资金流向等
   - 无需配置

3. 局域网ClickHouse（可选）
   - 同花顺板块历史数据（行业+概念题材）
   - 地址：192.168.10.102:18123
   - 注意：只有在家庭局域网内才能访问
   - 离开局域网后，板块页面数据会缺失，但其他页面正常

五、常见问题
----------------------------------------
Q: 打开页面后数据不显示？
A: 检查server.py是否正在运行（任务管理器看python进程）

Q: 板块页面没有数据？
A: 你不在家庭局域网，连不上飞牛OS的ClickHouse数据库
   - 大盘、宏观、个股页面正常
   - 板块行业页面需要在家才能看完整数据

Q: 端口被占用？
A: 修改server.py最后一行的5000改成其他端口（如8080）

六、开机自启动
----------------------------------------
如果需要开机自动启动服务：
1. 右键 "A股看板数据服务.lnk"
2. 复制到：C:\Users\你的用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
3. 重启电脑后会自动运行
